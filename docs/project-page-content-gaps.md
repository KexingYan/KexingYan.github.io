# Project Page Content Gaps

**Review date:** 2026-07-31
**Scope:** Phase 7 decision record

## Decision

No standalone project page is justified by the current public repository.

The only substantial project-like material is the public analysis code
associated with the microloan student paper. It is already linked from the
canonical research page and is best understood as a research companion, not a
separate software product. Creating a second project route would duplicate the
same work and blur its student-paper status.

## Market Radar

Market Radar is not named or described in the current website repository, its
visible pages, or the intentionally linked public profiles and research
repository reviewed for this phase. No page was created.

A future public page would require owner-approved, non-sensitive evidence for:

- the exact public project name and one-sentence purpose;
- present development status;
- intended users and supported use cases;
- intentionally public repository or demonstration URL;
- verified architecture and technology stack;
- approved screenshots with descriptive context;
- public data sources and their terms;
- limitations and non-advisory boundaries;
- privacy and security statements safe for disclosure; and
- one meaningful content modification date.

The page must not disclose secrets, private repositories, local paths, personal
financial data, credentials, or internal operational details. It must not claim
users, adoption, returns, predictive accuracy, commercial availability,
benchmarks, or reliability without public evidence.

Once sufficient material exists, evaluate one narrow schema type—normally
`SoftwareSourceCode`, `SoftwareApplication`, `CreativeWork`, or
`ResearchProject`—instead of combining types for coverage.
